# **App Name**: EdgeAI Chat

## Core Features:

- Chat Interface: A user-friendly interface to send messages and view AI responses in a conversational format.
- Batch AI Response: Send a prompt to the AI and receive a complete generated response once available.
- Streaming AI Response: Receive AI generated content in real-time, displaying token-by-token as it's produced.
- Conversation History: Display a chronological history of user inputs and AI outputs within the current session.
- AI Configuration Tool: Provide a tool to adjust generative AI parameters like temperature and max output tokens to influence response style.
- Performance Insight Display: Visually indicate performance metrics such as cache status (edge-cached vs. live) for AI responses.

## Style Guidelines:

- The primary color, #3670E2 (a vibrant electric blue), is chosen to convey a sense of modern technology, efficiency, and intelligence, contrasting sharply yet harmoniously with the dark background to maintain prominence without being overly aggressive. It represents the active and intelligent aspects of the AI.
- The background color, #272B35 (a deep, desaturated blue-grey), provides a stable and professional base for the application. Its low brightness reduces eye strain and helps content, especially text, stand out. This muted tone ensures the focus remains on interaction and information, echoing the precision of an 'arsenal' with a contemporary feel.
- The accent color, #75DBEF (a bright cyan-blue), serves as a secondary highlight for interactive elements or status indicators, ensuring clear differentiation from the primary blue. This brighter, cooler hue enhances the app's modern and technical aesthetic while maintaining an analogous relationship with the primary blue for visual coherence.
- Headlines and body text will use 'Inter', a grotesque-style sans-serif, for its modern, machined, and objectively neutral aesthetic, ensuring high readability and a professional appearance for all conversational content and interface labels.
- For any display of code, parameters, or technical log outputs within the application, 'Source Code Pro', a monospaced sans-serif, will be used to maintain clear, legible formatting.
- Utilize a set of clean, minimalist line-art or filled icons. These icons should align with the technical, modern, and efficient visual theme, enhancing clarity without distracting from content.
- Implement a structured and responsive layout, prioritizing a clear separation between the conversation display and the user input area. A clean, modular design approach will enhance usability and content focus across different screen sizes.
- Incorporate subtle and functional animations for UI feedback, such as typing indicators for streaming AI responses, smooth transitions for message loading, and state changes for interactive elements. These animations will be designed to enhance user experience without feeling superfluous.
